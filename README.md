# Tela de Autenticação (Login)

Um projeto prático focado no desenvolvimento de uma interface de login (autenticação de usuário) limpa, moderna e amigável.

• Funcionalidades
- Formulário de login estruturado com campos de e-mail/usuário e senha.
- Estilização focada na experiência do usuário (UX), com efeitos de foco nos campos (inputs) e botão interativo.

• Tecnologias Utilizadas
- HTML5 
- CSS3
